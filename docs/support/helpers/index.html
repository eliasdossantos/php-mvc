Helpers

Funções globais e helpers de view carregados pelo Composer.

Helpers de aplicação

Em app/Support/Helpers/functions.php: URL/assets (url, asset, storageUrl, uploadUrl, route), redirect (redirect, safeRedirectTarget), flash/erros/old input (flash, hasFlash, old, errors, hasError, error), CSRF (csrf_field, csrf_token), escape (e), override de método (method_field), autenticação (auth, user, userId, userRole, isRole), ambiente, strings, datas, bytes e navegação (env, str_limit, slug, dateBR, dateTimeBR, diffForHumans, formatBytes, isActive, dump, dd).

Helpers de views

ViewHelper.php define emptyDataMessage, inputClass, erroInput, selected, checked, disabledIf, readonlyIf, oldOr, oldSelected, oldChecked, classNames, attr, paginationLinks, money, pluralize, initials e imageOr.

Segurança e escopo

SecurityHelper reúne gerar token, hash/verify de password, sanitização, e-mail válido, slug, mask de email e UUID v4. Mailer envia ou simula envio conforme driver. Helpers simplificam apresentação; não substituem validação/autorização. Escape strings dinâmicas com e().

<input value="<?= old('title', $post->title ?? '') ?>">
<option value="draft" <?= selected('draft', $status) ?>>Rascunho</option>

Exemplo de template

Use helpers de apresentação para manter o template curto, mas não misture autorização com visibilidade de botão: esconder um link não protege a action. Continue validando e autorizando no servidor.

<form method="POST" action="<?= e(url('auth/login')) ?>">
    <?= csrf_field() ?>
    <input name="email" value="<?= old('email') ?>">
    <?php if (hasError('email')): ?>
        <span><?= e(error('email')) ?></span>
    <?php endif; ?>
</form>

Contrato dos helpers de formulário e apresentação

Os helpers são funções globais carregadas pelo autoload do projeto. Abaixo estão os contratos que afetam formulários, navegação, paginação e exibição; a referência de API lista todos os parâmetros/tipos extraídos.

FunçãoContrato/retornoUso e observações
old(string $key, string $default = ''): stringString escapada para HTMLRepõe o valor e já aplica escaping; não chame e() novamente.
oldOr($key, $fallback)Combina old input e fallbackold() escapa o valor anterior; o fallback pode voltar cru. Evite usar em saída não confiável sem tratar cada ramo.
e(mixed $value): stringTexto escapadoEscapa HTML; arrays viram JSON e objetos sem __toString viram nome da classe.
error($field): string, errors(): arrayMensagens sem escapeAplique e() ao imprimir mensagem em HTML, como faz o componente alerts.php.
method_field(string $method): stringInput hidden _methodRecebe string, por exemplo method_field('PUT'); não passe identificador sem aspas.
csrf_field(): string, csrf_token(): stringCampo HTML ou tokenUsados em forms e metadado; CsrfMiddleware precisa estar associado à rota.
route($name, $params = []): stringURL de rota nomeadaSe a resolução falhar, registra erro e cai para a URL da aplicação; não equivale a validação de rota.
redirect($path): never, safeRedirectTarget(...): stringRedirecionamento terminal/alvo seguroURLs externas não confiáveis são rejeitadas pelo helper de destino seguro.

ViewHelper: classes, estados e apresentação

ViewHelper.php define 17 funções globais. selected()/checked() devolvem fragmentos HTML para controles; disabledIf()/readonlyIf() produzem atributos conforme condição. inputClass()/erroInput() ajudam a mostrar validação, mas os valores/classes passados não são todos escapados automaticamente.

FunçãoParâmetros/retornoObservações
emptyDataMessage(string $message = 'Não há dados para serem exibidos.'): stringGera span com mensagem escapadaRecebe a mensagem final; não aceita contagem nem pluraliza.
oldSelected(string $field, mixed $value, mixed $fallback = null): string, oldChecked(...)Fragmento de atributo HTMLCompara entrada antiga com valor atual; revisar escaping no contexto do atributo.
classNames(array $classes): stringString com classes ativasNão escapa automaticamente tokens de classe.

money(float|int|string $value, string $prefix = 'R$ '): string, pluralize(...)Strings formatadasHelpers de apresentação; não validam entrada de negócio.

Dois contratos de paginação

// Componente real: recebe o resultado de Model::paginate dentro de data.


// Helper global: recebe resultado e URL base como argumentos distintos.
echo paginationLinks($result, url('users'), 'page', 2);

Não trate paginationLinks() e components/pagination.php como a mesma API: um produz links a partir de baseUrl/pageParam/window; o componente lê $_GET e espera o array em $data.

Override de método e escaping em template

method_field(string $method): string gera o campo oculto para enviar PUT/PATCH/DELETE em um formulário HTML POST. O Router só honra esses três valores em POST; a função não acrescenta novos verbos suportados nem converte uma requisição GET em PUT.

<form method="POST" action="/users/42">
    <?= csrf_field() ?>
    <?= method_field('PUT') ?>
    <button type="submit">Salvar</button>
</form>

old('email') já retorna valor escapado para HTML; use value="<?= old('email') ?>", sem e() adicional. Se oldOr() devolver o fallback cru, escape esse ramo de acordo com o contexto de saída.
