Instalação rápida

composer create-project elias-antonio/php-mvc php-mvc
cd php-mvc

# O script pós-criação copia .env.example e instala dependências.
# Ajuste .env; se necessário, gere APP_KEY.
php mvc key:generate
php mvc migrate
php mvc serve

Configure APP_URL, banco MySQL e variáveis de ambiente antes de iniciar. Em produção, APP_URL é obrigatória. Veja o guia completo de instalação.

$router->get('/', [HomeController::class, 'index'])->name('home');

Primeiro ciclo verificável

Depois de configurar o banco, use o CLI para conferir os comandos disponíveis, aplicar migrations pendentes e iniciar o servidor local. Execute os comandos na raiz do projeto; o servidor local não substitui a configuração do servidor web de produção.

php mvc list
php mvc migrate
php mvc serve

Antes de experimentar rotas, confirme APP_URL e as credenciais MySQL. Para investigar uma requisição completa, siga o ciclo da requisição.

Comportamento atual da rota inicial

A implementação da rota / distingue visitantes e usuários autenticados. Para visitantes, HomeController::index() renderiza home.index com o layout home. Para usuários autenticados, a action chama redirect('dashboard').

Limitação verificada no código: o helper de redirecionamento aceita caminhos locais iniciados por / e URLs absolutas permitidas; a string relativa dashboard é rejeitada e substituída pelo fallback de APP_URL (ou /). Assim, o fluxo atual não garante o destino /dashboard e pode redirecionar para a própria home repetidamente. Não trate o redirecionamento como funcional até corrigir o chamador para usar /dashboard e testar a configuração da URL base. A documentação registra o comportamento presente; não altera o código do framework.
