Design

Arquitetura em Camadas

Cada camada tem uma responsabilidade única. Nenhuma camada sabe mais do que precisa sobre as outras.

🌐 HTTP RequestChega em public/index.php → bootstrap/app.php
🛣 RouterResolve URI → Controller@method, aplica middlewares
🔒 MiddlewaresAuth, CSRF, Role — executados antes do controller
🎮 ControllerLê request, chama Service ou Repository, retorna View/JSON
⚙️ ServiceLógica de negócio pura — sem HTTP, sem HTML
📦 RepositoryQueries SQL encapsuladas e reutilizáveis
🗄 Model + DatabaseActive Record sobre PDO com prepared statements

Regra de ouro por camada

Camada ✅ Deve ter ❌ Não deve ter
Controller Ler request, chamar Service, retornar View/JSON Queries SQL, regras de negócio complexas
Service Lógica de negócio, orquestração, validações de domínio $_POST, header(), HTML, redirect()
Repository Queries SQL da entidade, buscas customizadas Lógica de negócio, validações
Model Estrutura da tabela, fillable, queries simples Lógica de apresentação, HTTP
Core

Router

Roteamento desacoplado com grupos, parâmetros dinâmicos, middlewares e rotas nomeadas.

routes/web.php
<?php
use App\Controllers\PostController;
use Core\Router;

/** @var Router $router */

// Rotas simples
$router->get('/posts',         [PostController::class, 'index'])->name('posts.index');
$router->post('/posts',        [PostController::class, 'store'],   ['CsrfMiddleware']);
$router->get('/posts/{id}',    [PostController::class, 'show'])->name('posts.show');
$router->put('/posts/{id}',    [PostController::class, 'update'],  ['CsrfMiddleware']);
$router->delete('/posts/{id}', [PostController::class, 'destroy'], ['CsrfMiddleware']);

// Parâmetro opcional
$router->get('/archive/{year?}', [PostController::class, 'archive']);

// CRUD completo — 7 rotas de uma vez
$router->resource('/posts', PostController::class);
// Ou apenas algumas:
$router->resource('/posts', PostController::class, only: ['index', 'store', 'destroy']);

// Grupos com prefixo e middleware compartilhado
$router->group(['prefix' => '/dashboard', 'middleware' => ['AuthMiddleware']], function (Router $r) {
    $r->get('', [DashboardController::class, 'index'])->name('dashboard');
    $r->get('/posts', [PostController::class, 'index']);

    // Sub-grupo dentro do grupo
    $r->group(['prefix' => '/admin', 'middleware' => ['RoleMiddleware:admin']], function (Router $r) {
        $r->get('/users', [AdminController::class, 'users']);
    });
});

// Rota nomeada → gera URL com route()
$router->get('/login', [AuthController::class, 'loginForm'])->name('auth.login');
echo route('auth.login');              // → https://app.com/login
echo route('posts.show', ['id' => 5]); // → https://app.com/posts/5

Middlewares

Filtros executados antes do controller. Quatro middlewares incluídos, prontos para usar.

Middleware O que faz Uso
AuthMiddleware Redireciona para login se não autenticado Rotas da área logada
GuestMiddleware Redireciona para dashboard se já logado Login, registro
CsrfMiddleware Valida token CSRF em POST/PUT/DELETE Formulários e APIs
RoleMiddleware:admin Exige role específica após autenticação Áreas restritas
Criando um middleware personalizado
<?php
namespace App\Middlewares;

use Core\Request;
use Core\Session;

class SubscriberMiddleware
{
    public function handle(Request $request): void
    {
        $user = Session::get('user');

        if (!$user || $user->plan !== 'premium') {
            $request->isJson()
                ? (http_response_code(403) and die(json_encode(['error' => 'Premium required'])))
                : (Session::flash('error', 'Recurso exclusivo para assinantes Premium.')
                   and redirect('dashboard'));
        }
    }
}

// Uso nas rotas:
$router->get('/premium', [ContentController::class, 'index'], ['AuthMiddleware', 'SubscriberMiddleware']);

Controller

Todos os controllers herdam de Core\Controller e ganham um arsenal de helpers para views, JSON, redirecionamento e validação.

app/Controllers/PostController.php
<?php
namespace App\Controllers;

use Core\Controller;
use App\Services\PostService;
use App\Repositories\PostRepository;

class PostController extends Controller
{
    private PostService    $service;
    private PostRepository $repo;

    public function __construct()
    {
        $this->service = new PostService();
        $this->repo    = new PostRepository();
    }

    // Renderiza view com layout
    public function index(): void
    {
        $posts = $this->repo->paginate(15, (int)($_GET['page'] ?? 1));

        $this->view('posts.index', [
            'title' => 'Posts',
            'posts' => $posts,
        ]); // usa layouts/main.php por padrão
    }

    // View com layout alternativo
    public function create(): void
    {
        $this->view('posts.create', ['title' => 'Novo Post'], 'main');
    }

    // Valida → redireciona se falhar → continua se OK
    public function store(): void
    {
        $this->validate($_POST, [
            'title'   => 'required|min:3|max:200',
            'content' => 'required|min:10',
            'status'  => 'required|in:draft,published',
        ]);

        $result = $this->service->create($_POST, $this->userId());

        $result['success']
            ? $this->redirectWith('dashboard/posts', 'success', 'Post criado!')
            : $this->redirectWith('dashboard/posts/create', 'error', $result['message']);
    }

    // Resposta JSON (para APIs)
    public function apiList(): void
    {
        $posts = $this->repo->paginate(10);
        $this->jsonSuccess('OK', ['posts' => $posts]);
    }

    // Abort com código HTTP
    public function show(int $id): void
    {
        $post = $this->repo->findById($id);
        $this->abortUnless((bool)$post, 404, 'Post não encontrado');
        $this->view('posts.show', compact('post'));
    }
}

Métodos disponíveis

Método Descrição
view($view, $data, $layout) Renderiza view com layout (padrão: main)
viewOnly($view, $data) Renderiza view sem layout
redirect($url) Redireciona para URL
back() Redireciona para a URL anterior
redirectWith($url, $type, $msg) Redireciona + flash message
json($data, $status) Resposta JSON com status HTTP
jsonSuccess($msg, $data, $status) JSON {"success":true,...}
jsonError($msg, $status) JSON {"success":false,...}
validate($data, $rules) Valida e redireciona de volta se falhar
auth() bool — está logado?
user() object — dados do usuário logado
userId() int — ID do usuário logado
abort($code, $msg) Lança exceção HTTP
abortUnless($cond, $code) Aborta se condição for falsa
abortIf($cond, $code) Aborta se condição for verdadeira

Model & Query Builder

Active Record com query builder fluente. Cada model mapeia uma tabela e herda CRUD completo, paginação e soft delete.

app/Models/Post.php
<?php
namespace App\Models;

use Core\Model;

class Post extends Model
{
    protected string $table      = 'posts';
    protected array  $fillable   = ['title', 'content', 'status', 'user_id', 'slug'];
    protected array  $hidden     = ['deleted_at'];    // campos ocultos na serialização
    protected bool   $timestamps = true;              // created_at / updated_at automáticos
    protected bool   $softDelete = false;             // true → usa deleted_at ao invés de DELETE

    // Método customizado (vai no Model quando é simples)
    public function findBySlug(string $slug): object|false
    {
        return $this->findBy('slug', $slug);
    }
}
Uso do Query Builder
$post = new Post();

// CRUD básico
$post->all();                               // SELECT * ORDER BY id
$post->all('created_at', 'DESC');          // ORDER BY created_at DESC
$post->find(42);                           // WHERE id = 42 LIMIT 1
$post->findBy('slug', 'meu-post');         // WHERE slug = '...' LIMIT 1
$post->create(['title' => 'Oi', 'user_id' => 1]); // INSERT → retorna lastInsertId
$post->update(42, ['title' => 'Oi!']);     // UPDATE WHERE id = 42
$post->delete(42);                         // DELETE (ou soft delete)

// Query builder fluente
$post->where('status', 'published')
     ->where('user_id', 5)
     ->orderBy('created_at', 'DESC')
     ->limit(10)
     ->get();                              // → array de objetos

$post->where('status', 'published')->count();
$post->where('email', $email)->exists();
$post->where('status', 'published')->first();

// SELECT específico
$post->select('id', 'title', 'created_at')
     ->where('status', 'published')
     ->get();

// Paginação
$result = $post->where('status', 'published')
               ->paginate(15, (int)($_GET['page'] ?? 1));
// $result = [
//   'data'      => [...],   ← array de objetos
//   'total'     => 120,
//   'page'      => 1,
//   'per_page'  => 15,
//   'last_page' => 8,
//   'from'      => 1,
//   'to'        => 15,
// ]

Database

Singleton PDO com interface fluente para queries seguras e transações.

Queries diretas e transações
$db = Core\Database::getInstance();

// Query simples com bind (prepared statement — sempre seguro)
$user = $db->query("SELECT * FROM users WHERE email = :e AND active = 1")
           ->bind(':e', $email)
           ->fetch();                     // → objeto | false

$users = $db->query("SELECT * FROM users WHERE role = :r ORDER BY name")
            ->bind(':r', 'admin')
            ->fetchAll();                 // → array de objetos

// INSERT / UPDATE / DELETE
$db->query("INSERT INTO logs (user_id, action) VALUES (:uid, :act)")
   ->bind(':uid', $userId)
   ->bind(':act', 'login')
   ->execute();

$lastId = $db->lastInsertId();
$rows   = $db->rowCount();

// Transação com closure (commit automático, rollback em exceção)
$db->transaction(function ($db) use ($userId, $data) {
    $db->query("UPDATE wallets SET balance = balance - :v WHERE user_id = :uid")
       ->bind(':v', $data['amount'])->bind(':uid', $userId)->execute();

    $db->query("INSERT INTO transactions (user_id, amount, type) VALUES (:uid, :v, 'debit')")
       ->bind(':uid', $userId)->bind(':v', $data['amount'])->execute();
});

// Transação manual
$db->beginTransaction();
try {
    // ... queries ...
    $db->commit();
} catch (\Throwable $e) {
    $db->rollback();
    throw $e;
}

Request

Encapsula a requisição HTTP com sanitização automática em todos os getters de entrada.

Uso do Request
$req = new Core\Request();

// Método e URI
$req->method();             // 'GET', 'POST', 'PUT', 'DELETE'
                            // Suporta override via campo hidden _method
$req->uri();                // '/dashboard/posts/42'
$req->isGet(); $req->isPost(); $req->isAjax(); $req->isJson();

// Dados de entrada (sanitizados)
$req->get('page', 1);       // $_GET com default
$req->post('name');         // $_POST sanitizado
$req->all();                // todos os $_POST sanitizados
$req->input('q');           // busca em POST e GET, nessa ordem
$req->raw('content');       // sem sanitização (para markdown, HTML editor, etc.)
$req->has('email');         // bool: campo existe?

// JSON body (para APIs)
$data  = $req->json();          // array completo
$title = $req->json('title');   // campo específico

// Arquivos
$req->file('avatar');           // dados de $_FILES
$req->hasFile('avatar');        // bool

// Meta
$req->ip();                     // IP real (respeita proxies)
$req->header('Authorization');  // header HTTP
$req->userAgent();

Uso da Session
use Core\Session;

// CRUD básico
Session::set('chave', $valor);

Session::hasFlash('error');            // bool

$token = Session::csrfToken();         // gera ou retorna token existente
Session::validateCsrf($token);         // bool — valida token enviado
Session::regenerateCsrf();             // novo token (após uso)

Auth

Sistema de autenticação genérico e plugável. Funciona com qualquer Model que implemente authenticate().

Uso do Auth
use Core\Auth;

// Login
if (Auth::attempt($email, $password)) {
    redirect('dashboard');
}

// Verificações
Auth::check();              // bool: está logado?
Auth::guest();              // bool: não está logado?
Auth::user();               // object: {id, name, email, role}
Auth::id();                 // int|null
Auth::role();               // string: 'admin', 'member', ...
Auth::is('admin');          // bool: tem essa role?
Auth::isAny('admin','editor'); // bool: tem alguma dessas?

// Guards (redirecionam se condição não atendida)
Auth::require('auth/login');              // exige login
Auth::requireRole('admin', 'dashboard'); // exige role

// Logout
Auth::logout();

// Login manual (após OAuth, registro automático, etc.)
$user = (new User())->find($id);
Auth::loginUser($user);
Auth::loginUser($user, remember: true);

// Usar modelo de usuário diferente
Auth::setUserModel(AdminUser::class);

Validação

20+ regras de validação com mensagens em português. Integrado ao Controller Base para redirecionar automaticamente em caso de falha.

Uso do Validator
use Core\Validator;

// Factory estática
$v = Validator::make($_POST, [
    'name'     => 'required|min:2|max:100',
    'email'    => 'required|email|unique:users,email',
    'password' => 'required|min:6|confirmed',  // exige password_confirmation
    'age'      => 'required|integer',
    'website'  => 'nullable|url',
    'role'     => 'required|in:admin,editor,viewer',
    'user_id'  => 'required|exists:users,id',
]);

if ($v->fails()) {
    $errors = $v->errors();          // ['email' => ['E-mail já em uso.'], ...]
    $first  = $v->firstError();      // 'Nome é obrigatório.'
    $field  = $v->firstError('email');
}

// No Controller — valida e redireciona de volta automaticamente:
$this->validate($_POST, [
    'title' => 'required|min:3',
    'email' => 'required|email',
]);
// Se falhar: salva erros na sessão, redireciona para URL anterior
// Se passar: continua normalmente

Todas as regras

Regra Descrição
required Campo obrigatório (não vazio)
min:N Mínimo de N caracteres (string) ou valor N (número)
max:N Máximo de N caracteres (string) ou valor N (número)
email E-mail válido via filter_var
url URL válida
numeric Valor numérico
integer Número inteiro
alpha Apenas letras
alphanumeric Letras e números
date Data válida via strtotime()
confirmed Deve ser igual a {campo}_confirmation
same:outro Deve ser igual ao campo especificado
different:outro Deve ser diferente do campo especificado
in:a,b,c Deve estar na lista de valores
not_in:a,b,c Não deve estar na lista
regex:/pattern/ Deve corresponder à expressão regular
unique:tabela,col Valor único no banco (unique:users,email,{id_ignorado})
exists:tabela,col Deve existir no banco
nullable Permite vazio — pula as demais regras se vazio

FormRequests

Camada dedicada a centralizar validação, sanitização e autorização de cada formulário. Mantém os Controllers finos e sem lógica de entrada.

💡
Por que usar FormRequests?

Sem essa camada, validações ficam espalhadas nos Controllers. Com ela, cada formulário tem sua própria classe com regras, mensagens e sanitização isoladas, reutilizáveis e testáveis de forma independente.

Estrutura

app/Requests/ ├── FormRequest.php ← Classe base — estenda esta para criar novos requests ├── Auth/ │ ├── LoginRequest.php │ ├── RegisterRequest.php │ ├── ForgotPasswordRequest.php │ └── ResetPasswordRequest.php └── Users/ ├── StoreUserRequest.php └── UpdateUserRequest.php

Fluxo interno

new LoginRequest()Captura dados da requisição: $_POST, JSON body, $_FILES
authorize()Verifica permissão — retorna false → 403 imediato
sanitize()Limpa e normaliza os dados (trim, lowercase, strip_tags…)
validate(rules())Aplica regras do Core\Validator com messages() customizadas
validated()Retorna apenas os campos válidos e limpos para usar no Service

Criando um FormRequest

app/Requests/Posts/StorePostRequest.php
<?php
namespace App\Requests\Posts;

use App\Requests\FormRequest;
use Core\Auth;

class StorePostRequest extends FormRequest
{
    // Quem pode realizar esta ação?
    public function authorize(): bool
    {
        return Auth::check(); // apenas usuários logados
    }

    // Regras de validação (mesma sintaxe do Core\Validator)
    public function rules(): array
    {
        return [
            'title'   => 'required|min:3|max:255',
            'content' => 'required|min:10',
            'status'  => 'required|in:draft,published',
            'slug'    => 'nullable|max:260|unique:posts,slug',
        ];
    }

    // Mensagens customizadas — formato: 'campo.regra' => 'mensagem'
    public function messages(): array
    {
        return [
            'title.required' => 'O título é obrigatório.',
            'title.min'      => 'O título deve ter pelo menos 3 caracteres.',
            'content.required' => 'O conteúdo é obrigatório.',
            'status.in'      => 'Status inválido. Use: draft ou published.',
            'slug.unique'    => 'Este slug já está em uso.',
        ];
    }

    // Sanitização customizada — executada ANTES da validação
    public function sanitize(): array
    {
        return [
            'title'   => ucfirst(trim($this->input['title']   ?? '')),
            'content' => trim($this->input['content'] ?? ''),
            'status'  => trim($this->input['status']  ?? 'draft'),
            'slug'    => !empty($this->input['slug'])
                           ? slug($this->input['slug'])
                           : slug($this->input['title'] ?? ''),
        ];
    }
}

Uso no Controller

app/Controllers/PostController.php
<?php
namespace App\Controllers;

use Core\Controller;
use Core\Session;
use App\Requests\Posts\StorePostRequest;
use App\Services\PostService;

class PostController extends Controller
{
    public function store(): void
    {
        // 1. Instancia o Request → valida no construtor automaticamente
        $request = new StorePostRequest();

        // 2. Se falhar: redireciona de volta com o primeiro erro
        if ($request->fails()) {
            Session::flash('error', $request->firstError());
            Session::flashInput($request->all()); // salva inputs para repopular form
            $this->back();
        }

        // 3. Delega para o Service com dados já limpos e validados
        $result = (new PostService())->create(
            $request->validated(),
            $this->userId()
        );

        $result['success']
            ? $this->redirectWith('dashboard/posts', 'success', 'Post criado!')
            : $this->redirectWith('dashboard/posts/create', 'error', $result['message']);
    }
}

API do FormRequest

Método Retorno Descrição
fails() bool True se a validação falhou
passes() bool True se a validação passou
errors() array Todos os erros: ['campo' => ['msg',...]]
firstError() ?string Primeiro erro global
firstError('email') ?string Primeiro erro do campo
validated() array Dados válidos e sanitizados — use no Service
get('campo') mixed Campo específico do validated()
old('campo') mixed Valor anterior (para repopular form)
all() array Todos os dados sanitizados (antes da validação)

1. Migration — database/migrations/002_create_posts_table.sql
CREATE TABLE IF NOT EXISTS posts (
    id         INT UNSIGNED  AUTO_INCREMENT PRIMARY KEY,
    user_id    INT UNSIGNED  NOT NULL,
    title      VARCHAR(255)  NOT NULL,
    slug       VARCHAR(260)  NOT NULL UNIQUE,
    content    TEXT          NOT NULL,
    status     ENUM('draft','published') NOT NULL DEFAULT 'draft',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_status (status),
    INDEX idx_user   (user_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

3. Repository — app/Repositories/PostRepository.php
<?php
namespace App\Repositories;

use Core\Repository;
use App\Models\Post;

class PostRepository extends Repository
{
    protected string $modelClass = Post::class;

    public function findPublished(int $page = 1): array
    {
        return $this->model()
            ->where('status', 'published')
            ->orderBy('created_at', 'DESC')
            ->paginate(15, $page);
    }

    public function findByAuthor(int $userId): array
    {
        return $this->model()->where('user_id', $userId)->orderBy('created_at', 'DESC')->get();
    }
}
4. Service — app/Services/PostService.php
<?php
namespace App\Services;

use Core\Service;
use Core\Logger;
use App\Repositories\PostRepository;

class PostService extends Service
{
    public function __construct(
        private readonly PostRepository $posts = new PostRepository()
    ) {}

    public function create(array $data, int $userId): array
    {
        $id = $this->posts->create([
            'user_id' => $userId,
            'title'   => $data['title'],
            'slug'    => slug($data['title']),
            'content' => $data['content'],
            'status'  => $data['status'] ?? 'draft',
        ]);

        if (!$id) return ['success' => false, 'message' => 'Erro ao criar post.'];

        Logger::info('Post criado', ['id' => $id, 'user_id' => $userId]);
        return ['success' => true, 'id' => $id];
    }

    public function delete(int $postId, int $userId): array
    {
        $post = $this->posts->findById($postId);
        if (!$post || (int)$post->user_id !== $userId)
            return ['success' => false, 'message' => 'Sem permissão.'];

        $this->posts->delete($postId);
        return ['success' => true];
    }
}
5. Controller — app/Controllers/PostController.php 
<?php
namespace App\Controllers;

use Core\Controller;
use App\Services\PostService;
use App\Repositories\PostRepository;

class PostController extends Controller
{
    private PostService    $service;
    private PostRepository $repo;

    public function __construct()
    {
        $this->service = new PostService();
        $this->repo    = new PostRepository();
    }

    public function index(): void
    {
        $this->view('posts.index', [
            'title' => 'Posts',
            'posts' => $this->repo->findPublished((int)($_GET['page'] ?? 1)),
        ]);
    }

    public function store(): void
    {
        $this->validate($_POST, [
            'title'   => 'required|min:3|max:255',
            'content' => 'required|min:10',
        ]);
        $result = $this->service->create($_POST, $this->userId());
        $result['success']
            ? $this->redirectWith('dashboard/posts', 'success', 'Post criado!')
            : $this->redirectWith('dashboard/posts', 'error', $result['message']);
    }

    public function destroy(int $id): void
    {
        $result = $this->service->delete($id, $this->userId());
        $this->json(['success' => $result['success'], 'message' => $result['message'] ?? '']);
    }
}

O boilerplate já está preparado para APIs JSON. Use os métodos do Controller base.

Controller de API
<?php
namespace App\Controllers;

use Core\Controller;

class ApiPostController extends Controller
{
    public function index(): void
    {
        $posts = (new PostRepository())->paginate(10, (int)($_GET['page'] ?? 1));
        $this->jsonSuccess('OK', ['posts' => $posts]);
    }

    public function store(): void
    {
        // Lê JSON body (Content-Type: application/json)
        $data = json_decode(file_get_contents('php://input'), true) ?? [];

        if (empty($data['title'])) {
            $this->jsonError('Título obrigatório.', 422);
        }

        $id = (new Post())->create(['title' => $data['title'], 'user_id' => $this->userId()]);
        $this->jsonSuccess('Post criado.', ['id' => $id], 201);
    }

    public function destroy(int $id): void
    {
        $post = (new Post())->find($id);
        $this->abortUnless($post && (int)$post->user_id === $this->userId(), 403);
        (new Post())->delete($id);
        $this->json(['success' => true], 204);
    }
}

Guia

Segurança

Proteções ativas por padrão. Nenhuma configuração adicional necessária para os casos comuns.

CSRF — Cross-Site Request Forgery

Formulários HTML
<form method="POST" action="<?= url('posts') ?>">
    <?= csrf_field() ?>   <!-- <input type="hidden" name="_csrf_token" value="..."> -->
    ...
</form>
AJAX / fetch
// O apiFetch() já inclui o token automaticamente via meta tag
const result = await apiFetch('/api/posts', { method: 'POST', body: JSON.stringify(data) });

// Manual:
fetch('/api/posts', {
    method: 'POST',
    headers: { 'X-CSRF-Token': document.querySelector('meta[name="csrf-token"]').content },
    body: JSON.stringify(data),
});

XSS — Cross-Site Scripting

Sempre use e() nas views
// ✅ Correto — escapa entidades HTML
echo e($user->name);
echo e($post->title);

// ❌ NUNCA faça isso — vulnerável a XSS
echo $user->name;
echo "<h1>{$post->title}</h1>";

SQL Injection

Prepared statements em todo lugar
// ✅ Seguro — prepared statement automático
$user = (new User())->findBy('email', $email);
$user = (new User())->where('email', $email)->first();

// ✅ Seguro — bind manual
$db->query("SELECT * FROM users WHERE email = :e")->bind(':e', $email)->fetch();

// ❌ NUNCA interpolue variáveis em SQL
$db->query("SELECT * FROM users WHERE email = '$email'"); // vulnerável!

Headers de Segurança

Configurados automaticamente em dois lugares: public/.htaccess (Apache) e Core\Application::setSecurityHeaders() (PHP).

Header Valor padrão Proteção
X-Content-Type-Options nosniff Evita MIME sniffing
X-Frame-Options SAMEORIGIN Evita clickjacking
X-XSS-Protection 1; mode=block XSS em browsers antigos
Referrer-Policy strict-origin-when-cross-origin Privacidade de URL
